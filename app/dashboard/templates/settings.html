Quick Setup Guide
  1. Copy .env.example → .env and fill in your API keys.
  2. Run python scripts/seed_db.py to add default PW sources.
  3. Run python scripts/setup_telegram.py once to authenticate Telegram.
  4. Click Collect Now in the sidebar to pull first batch of updates.
  5. Go to Updates, promote interesting items to posts.
  6. Review captions in the editor, then schedule or post immediately.
  7. For Instagram posting, set INSTAGRAM_BUSINESS_ACCOUNT_ID + INSTAGRAM_ACCESS_TOKEN (Graph API).
